Methodology · this run

Weighted Laspeyres price index

Indext = [ Σ(Pt · Q0) / Σ(P0 · Q0) ] × 100

Pt is the median of the fares that passed the IQR fence for this corridor; P0 is the base-year (2022) median fare, Q0 the base-year passenger-volume weight from DGCA. The basket is fixed at the base period, so the index isolates pure price change. This prototype audits one corridor per run — the national index is the Q0-weighted sum across all audited corridors.

Two-tailed IQR outlier filter

fence = [ Q1 − k·IQR , Q3 + k·IQR ]

Fares outside the fence are excluded before the median is taken. k is analyst-set; a lower k is stricter. The filter runs when you press Execute — the slider alone does not recompute it.

Festival adjustment

Fares within ±7 days of a gazetted festival (via the holidays.India() dataset) are tagged; the ex-festival index re-computes with them removed so seasonal spikes don't leak into the trend.

Acquisition

Automated headless-browser scraping of airline + OTA portals (Playwright), XHR-response interception, and a vision-LLM self-healing extractor. See engineering deep-dive §2A. The Import CSV button loads a pre-scraped fare extract for the selected route in place of a live scrape.
